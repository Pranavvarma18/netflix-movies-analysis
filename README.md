\# Netflix Movies Data Analysis



\## Overview



This project performs exploratory data analysis on Netflix movie

data using Python, Pandas, NumPy, Matplotlib, and Seaborn.



The goal is to identify patterns in movie genres, ratings, countries,

release years, and movie duration.



\## Objectives



\- Identify the most common movie genres

\- Analyze movies released after 2015

\- Identify countries with the highest number of movies

\- Find the longest movie

\- Analyze year-wise movie trends

\- Study genre frequency

\- Analyze rating distributions



\## Dataset



Source: Kaggle Netflix Movies and TV Shows Dataset



The dataset contains information about Netflix titles including

title, director, cast, country, release year, rating, duration,

and genre/category information.



\## Technologies



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Jupyter Notebook
